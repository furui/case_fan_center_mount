# Case Fan Center Mount Adapter

Parametric OpenSCAD adapter that mounts to two fan screw holes and adds a center tab for chassis screws. Supports 80/92/120/140 mm fans and custom dimensions.

## Usage

1. Open `case fan center mount adapter.scad` in OpenSCAD.
2. Set the fan preset and other options in the Customizer.
3. Render and export an STL.

The `sealed` option adds a matching mount on the opposite side of the fan and a perimeter ring. `center_hole_mode` selects threaded or pilot center holes.
